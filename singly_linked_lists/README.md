# Singly linked lists

Apprendre à créer et utiliser une liste chaînée en C.

| Fichier | Rôle |
|---------|------|
| `lists.h` | Structure et prototypes |
| `0-print_list.c` | Affiche les éléments de la liste |

Compilation : `gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c`
